## What the automated visual checks inspect

`e2e/lab-04/responsive.spec.ts` checks page-level horizontal overflow, offscreen interactive controls, and mobile touch target height on dashboard, workflow, list, create, edit, assign, and Requester read-only states at desktop, tablet, mobile, and 200% zoom equivalent widths. `e2e/lab-04/accessibility.spec.ts` checks names, labels, heading structure, contrast, visible focus, error descriptions, keyboard dialogs, Escape, and focus return. `e2e/lab-04/dashboards.spec.ts` checks count and list links, role isolation, filtered query results, and loading/failure/Retry. `e2e/lab-04/polish.spec.ts` checks authenticated role screens for browser errors, unfinished copy, and placeholder links. The Lab 3 browser regression and visual suites continue to cover authentication, navigation, ownership, comments, notes, attachments, user management, and earlier responsive and accessibility behavior.
